# Vision

FOX helps engineering agents determine what to build, why an architecture is
appropriate, what could disprove its assumptions, and what observation should
change their course. It supplies structured tactics and durable evidence while
the host model supplies language understanding, creativity, and code generation.

The system must work before software exists. A human vision should lead to
competing candidate structures, explicit boundaries, failure models, and tests
that can expose a poor choice early. It must also work after failure, when the
right next action may be investigation rather than implementation.

The central promise is disciplined uncertainty: distinguish observations from
hypotheses, preserve contradictory evidence, and revise decisions for stated
reasons. FOX must not force every project into one milestone sequence or call
every strategy for every problem.

FOX is independent of CAE, Codex, any model vendor, and any particular host
operating system. Agent neutrality is a design target that requires integration
evidence on each supported host. The concept foundation is not evidence that
this approach is novel or improves real engineering outcomes. Comparative
benchmarks are part of the research agenda.
