# Changelog

## 0.1.0-concept

Initial experimental foundation for Falsification-Oriented eXploration.

- Define the five governing principles as contract and interface requirements.
- Establish deterministic analysis, an animal strategy registry, explicit
  hypothesis relationships, architecture alternatives, evidence preservation,
  and scoped authority policy.
- Add an agent-neutral Python SDK and versioned JSON lines integration.
- Document synthetic examples, CAE case attribution, security boundaries,
  continuity, and verification limitations.

Python packaging uses `0.1.0.dev0`. This concept checkpoint is not a production
release. Actual implementation and validation status lives in
[the continuity records](docs/continuity/).
